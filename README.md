# レルムズ・オブ・アルカニア シリーズ 日本語化プロジェクト

レルムズ・オブ・アルカニア（Realms of Arkania）シリーズを日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。
Steam・GOG.com で販売されている「Classic」版（DOS 版）を対象に、三部作を順に日本語化していきます。
開発元・販売元とは関係ありません。

- サイト（作品の紹介・入れ方）: https://higesho.github.io/arkania-ja/
- ダウンロード: [リリース](https://github.com/higesho/arkania-ja/releases)
- 同じ世界を舞台にした Drakensang の日本語化: https://higesho.github.io/drakensang-jp/
- ウルティマ シリーズの日本語化: https://higesho.github.io/ultima-ja/
